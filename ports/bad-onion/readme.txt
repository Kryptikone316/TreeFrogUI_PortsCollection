B) Getting Started
---------------------------------------------
Unzip the download to a directory and then 
run 'badonion.bat'. If for some reason 
that doesn't work, open the MSDOS CONSOLE and 
try the following:

Example:
		
c:\badonion\> fxi -f -b badonion.dcb

or you can run Bad Onion in a window...

c:\badonion\> fxi -w -b badonion.dcb

---------------------------------------------
C) Keys
---------------------------------------------
Key                    Action
---                    ------
Enter..................Start Game
ESCAPE.................Exit Game
ALT & X................Exit Game
Space..................Jump
Left Arrow Key.........Walk Left
Right Arrow Key........Walk Right

Cheats:

Press L = Warp to next level  
Press K = Extra Life
Press J = Extra Emeralds
