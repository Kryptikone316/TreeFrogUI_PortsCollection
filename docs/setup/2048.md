# 2048

Gabriele Cirulli's sliding-tile puzzle: slide the tiles, merge two with the same number into one, and try to make a tile
that reads 2048. When the board is full and nothing can merge, the game is over. You can keep going past 2048 for a
higher score.

This entry is the [libretro 2048 core](https://github.com/libretro/libretro-2048), built unmodified for the SF3500
(the source is the pinned `ports/2048/source` submodule, [Kryptikone316/2048-port](https://github.com/Kryptikone316/2048-port)). Everything needed is included; nothing has to be downloaded.

Select **2048** under **Games → Ports** to start.

## Controls

| Button | Action |
|---|---|
| D-pad | slide all tiles up, down, left or right |
| Start | begin a game from the title screen; pause during play |
| Select (while paused) | start a new game |
| Select (after reaching 2048) | keep playing |
| Select + Start | open the in-game menu (see below); **Exit** leaves the game |

Your best score is kept between sessions in `picoarch/2048/` on the SD card.

## Menu and options

**Select + Start** opens the in-game menu (picoarch's). Under **Options**:

- **Emulator options** has the game's own settings: **Theme** (Light or Dark) and **Framerate**. Both are marked
  "restart", so they apply the next time you start the game.
- **Audio and video → Aspect ratio** sets how the picture fills the screen. The game is drawn at 376×464, a tall
  picture, so try Integer, Native and Fill to see which you prefer.

## What is in the port folder

```text
roms/ports/2048/
├── 2048_libretro.so   # the game (a libretro core, run by picoarch)
├── 2048.dat           # a tiny placeholder; picoarch needs a file to load, the game does not use it
├── run.sh             # starts picoarch with the two files above
└── source/            # the pinned source this was built from (libretro-2048 plus a build script)
```
